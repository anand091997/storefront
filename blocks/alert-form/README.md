# alert-form Block

A minimal block that renders an input and a submit button. On submit, it shows a JavaScript alert with the entered text.

- Auto-injected on the homepage by `scripts/scripts.js` in `buildAutoBlocks`.
- No configuration keys or external dependencies.
- Files:
  - `alert-form.js` – builds the form and wires the submit handler
  - `alert-form.css` – minimal styling

Usage: open `/` and submit the form to see the test alert.
